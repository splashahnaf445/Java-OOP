# Java: OOP Fundamentals & GUI Programming

Java learning repository covering Object-Oriented Programming (OOP) fundamentals, graphical user interface (GUI) development, problem-solving, and practical coursework applications.

> **Repository Note:** Merged from the former `Java-OOP` and `Java-GUI` repositories with full commit history preserved.

---

## 📂 Repository Contents

| Directory | Description |
| :--- | :--- |
| **`01-OOP-Midterms/`** | Solutions to OOP midterm examination question sets (Fall-22, Summer-23, Fall-23, Spring-24). |
| **`02-GUI-Swing/`** | Desktop graphical user interface implementations using Swing and AWT, covering component layout and event handling mechanisms. |
| **`03-Assignment- Ride Sharing App/`** | Backend service system designed for a startup ride-sharing service, built in Java with custom exception case handling. |
| **`04-Lab mid exam Office Managing/`** | Practical lab midterm examination solution implementing an office management system. |

---

## 🛠️ Key Topics & Practical Implementations

* **Object-Oriented Programming (OOP):** Core principles, class architecture, and academic midterm assessments across multiple terms (Fall 2022 to Spring 2024).
* **Desktop GUI & Event Handling:** Graphical desktop programming utilizing Java Swing and AWT frameworks to capture and handle user events.
* **Application Architecture & Exception Handling:** Structured software design for startup service systems (e.g., Ride-Sharing application) incorporating robust exception case handling.
* **Management System Modeling:** Practical lab evaluation implementations covering office management operational workflows.
